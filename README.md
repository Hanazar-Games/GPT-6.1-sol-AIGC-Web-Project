# MIDNIGHT DRIFT · 午夜漂移

原创 3D Web 漂移赛车游戏。霧雨峠的夜间闭环山路、一辆可换色的后驱跑车，以及属于你的漂移轨迹。

## 游玩

- **W / ↑** 油门，**S / ↓** 刹车与倒车
- **A D / ← →** 转向，**Space** 手刹
- **B** 按住烧胎（低速时 **W + S** 也可），松开结束；触屏提供「烧胎」按钮
- **C** 切换三种镜头，**R** 返回最近的赛道路面
- **Esc** 暂停，车库中 **Enter** 开始
- 手机和平板提供多点触屏按钮，以及「镜头」「回正」快捷操作。右上角齿轮可切换「自动／流畅／精细」画质；选择会保留，驾驶中设置画质会暂停计时。右上角音符按钮开启合成发动机与轮胎声音。

动力、仪表和声音共用六挡自动换挡模型，转速来自后轮实际轮速，驱动力随挡位与转速变化，包含空挡、倒挡和换挡时的转速回落；升降挡采用不同阈值，减少临界速度下反复跳挡。引擎音调跟随转速，音色随油门负载变化，静音时暂停音频上下文。

入弯前减速，转向后短按手刹，让后轮开始滑动；松开手刹后及时向车尾滑出的方向反打，保持油门维持滑动，松油后后轮逐步恢复抓地。长按手刹会损失速度，入弯过快仍可能失去抓地。连续漂移提高倍率，回正 1.6 秒后分数入账；护栏碰撞或重置车辆会清空尚未结算的连击。

键盘和触屏默认带有限的轮胎回正辅助：起漂后更容易接住侧滑，主动反打响应更快。短按手刹后用方向与油门调整滑行；保持油门、松开方向也能延续已建立的漂移，左右换向可接续连击；松开方向并松油可退出漂移。追尾镜头会适度看向车辆实际行进方向，引擎盖镜头保持跟随车头。

短暂松油可收窄漂移角度，随后补油继续滑行；完全松油与方向则逐步收车。实际前轮角度和左右漂移目标都渐进变化，减少反打、补油和手刹修正时的突变。

烧胎使用前轮制动与后轮驱动：车身停住时后轮仍会旋转，转速、胎烟、胎印和轮胎声音随实际打滑变化。高速按 B 会先制动减速；按住 Space 会锁住后轮。烧胎不计漂移分数，释放 B 后按油门即可起步。

自由漂移不限时，挑战模式按实际驾驶时间限时 120 秒，暂停和切出窗口不消耗时间。两种模式的最高分、最快圈速和最佳漂移连击分别保存在当前浏览器本地。车库「驾驶档案」保留最近 20 次驾驶记录；车色、镜头和所选模式会在下次打开时恢复。旧版综合最高分保留在档案中，不混入新模式纪录。圈速在首次正向通过起点后开始；使用「回正」会使本圈失效，下一次过线后重新计时。

结束自由驾驶或完成限时挑战后，结算页显示驾驶时间、距离、最高速度、最佳漂移连击、完成圈数和最佳圈速。

存档写入前会合并其他标签页已经保存的纪录和驾驶记录，保留更高分数与更快圈速，并按驾驶 ID 去重；修改画质或镜头时只更新对应偏好。触屏与键盘可混合使用，取消触摸、移除触屏设备或切出窗口会释放相应输入。

## 本地运行

需要 Node.js 22 或更高版本。

```sh
npm ci
npm run dev
```

打开终端输出的本地地址。验证和生产构建：

```sh
npm test
npm run build
npm run preview
```

## GitHub Pages

`.github/workflows/pages.yml` 在推送到 `main` 时运行物理测试、构建并部署 `dist/`。在仓库 **Settings → Pages → Source** 中选择 **GitHub Actions**。首次部署需要仓库的 Pages 权限已开启。若首次运行在部署阶段失败，启用后可在 Actions 中选择 **Re-run failed jobs**，复用已生成的构建产物。

若仓库仍设置为分支发布，构建流程会通过 `actions: write` 取消同一提交产生的默认 Pages 工作流，避免未构建的源代码覆盖游戏。该权限仅授予构建任务；正式发布任务只获得 Pages 和 OIDC 写权限。推荐的发布来源仍是 GitHub Actions。

在线游玩：<https://hanazar-games.github.io/GPT-6.1-sol-AIGC-Web-Project/>。

Vite 使用相对资源路径，适配 GitHub Pages 项目子路径。游戏场景、车辆、轮胎烟雾与贴图均由代码生成；Three.js 随构建打包，无运行时 CDN 依赖。Barlow 字体随项目托管，运行时无需请求 Google Fonts；字体许可证保存在 `public/fonts/`。

## 实现

- Three.js / WebGL 2：程序化赛车、闭环样条赛道、森林、山脉、灯光、粒子与轮胎痕迹。
- 120 Hz 固定步长：平面三自由度车身动力学，独立前后轴侧偏角与非线性轮胎力、组合摩擦限制、后轮驱动、制动载荷转移、后轮手刹锁止、后轮旋转惯量、纵向滑移率和渐进踏板响应。车身倾斜、俯仰与前轮角度跟随物理状态。
- 数字转向按侧滑角和侧滑增长率调整有限的前轮角度；起漂后给油保留漂移目标，收油退出辅助并恢复抓地，不直接修改车身角速度或速度方向；极短手刹点按保留至少 0.12 秒物理输入，暂停、设备移除及触摸取消会清除相应待处理输入。
- 转向速率限制作用于最终实际前轮角度，涵盖手动输入与辅助切换；漂移辅助使用渐进油门状态调整角度。连贯漂移不会因短暂回正提前升挡；接近红线时，只有下一挡能提供更高后轮驱动力（计入换挡扭矩下降）才进行漂移升挡。
- 驾驶测试包含 12–24 m/s 入弯的持续漂移、给油时松开方向继续侧滑、松油两秒收车、数字按键左右换向接续连击、原地烧胎与高速制动进入烧胎，以及跨帧手刹点按。自动化结果用于回归；最终手感仍需要实机试玩评估。
- 这是为键盘和触屏调校的平面驾驶模型，尚未模拟独立车轮悬架、轮胎温度或垂向路面。建模参考 [Vehicle Body 3DOF](https://www.mathworks.com/help/vdynblks/ref/vehiclebody3dof.html) 与 [Chrono 轮胎模型文档](https://api.projectchrono.org/development/wheeled_tire.html)，参数属于游戏调校，未经实车标定。
- 赛道线段预建包围盒层次树，按距离剪枝，保留精确投影和确定性的线段编号；随机远近位置及全部赛道采样点与全量扫描结果逐项对照，确保定位、碰撞和圈速使用相同赛道坐标。
- 静态几何按材质合批，树木实例化，烟雾和轮胎痕迹复用固定资源池；小地图赛道底图只绘制一次。
- 自动画质按视口像素预算和持续帧耗时调整渲染清晰度；车库／暂停常规绘制限制在约 30 FPS，后台停止绘制，减少动态效果偏好下车库只在变化时重绘。
- Web Audio 合成声音，默认静音；切出窗口自动暂停。
- Node 内置测试覆盖驾驶稳定性、漂移触发、连击入账、碰撞、倒计时、混合输入、触屏取消与捕获失败、跨标签页存档合并和存储失败恢复，并用真实场景数学与模拟渲染器验证开始／暂停／重开、镜头与 WebGL 恢复流程。另有 180 秒赛道持续驾驶测试，检查碰撞恢复和整圈驾驶的稳定性。
- 自动化流程测试不包含真实 GPU 绘制；浏览器画面与移动设备性能仍需实机验证。
